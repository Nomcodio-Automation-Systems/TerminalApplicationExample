# Terminal Application Example

This project is a simple shell program that supports command execution, input/output redirection, background processes, and conditional command execution.

## Features

- Command execution
- Input/output redirection
- Background processes
- Conditional command execution

## Usage

1. Clone the repository.
2. Compile the source code using a C compiler.
3. Run the executable to start the shell.

## Files

- `Console Example.cpp`: Contains the implementation of the shell program.
- `Console.h`: Header file with function prototypes and global variables.
